Timing
Fire it when the words arrive

      
Every mark can wait for a cue. Let the page fire each one as its words scroll into view, or fire them yourself from code the moment your text lands: a typed line, a caption, a slide coming in. Both demos use the hand and speed picked above.

It is interesting to contemplate a tangled bank, clothed with many plants of many kinds, with birds singing on the bushes, with various insects flitting about, and with worms crawling through the damp earth, and to reflect that these elaborately constructed forms, so different from each other, and dependent upon each other in so complex a manner, have all been produced by laws acting around us.

          
These laws, taken in the highest sense, being Growth with Reproduction; Inheritance which is almost implied by reproduction; Variability from the indirect and direct action of the conditions of life, and from use and disuse: a Ratio of Increase so high as to lead to a Struggle for Life, and as a consequence to Natural Selection, entailing Divergence of Character and the Extinction of less-improved forms.

          
Thus, from the war of nature, from famine and death, the most exalted object which we are capable of conceiving, namely, the production of the higher animals, directly follows. There is grandeur in this view of life, with its several powers, having been originally breathed into a few forms or into one; and that, whilst this planet has gone cycling on according to the fixed law of gravity, from so simple a beginning endless forms most beautiful and most wonderful have been, and are being, evolved.

On a web page

        
Give a box as a CSS selector and it measures the element every frame, so the mark follows reflow. It waits until the element is half visible, then draws once. Reduced motion shows the finished frame.

        
<script src="annotationfx.js"></script>
<p id="quote">from so <span id="w1">simple</span> a beginning ...
  <span id="w3">evolved.</span></p>
<script>
  AnnotationFX.play('#quote', {
    style: 'darwin', bleed: 40,
    marks: [
      { mark: 'circle', box: '#w1' },
      { mark: 'arrow',  box: '#w3', note: 'I think' }
    ]
  });
</script>

        
No code: put the options on the element and load the script with data-auto.

        
<p data-annotate='{"style":"dali","mark":"circle","box":"#w1"}'>...</p>
<button data-annotate-replay="p">Replay</button>
<script src="annotationfx.js" data-auto></script>

      

      

        
Over photos and video

        
On an image or video, boxes are in the media's own pixels and respect object-fit. For video, give keyframes in seconds: the mark reads the video's clock, so it holds through a pause or a seek.

        
AnnotationFX.play(video, {
  style: 'feynman',
  mark: 'circle', note: 'draw the diagram',
  box: [{ t: 0, x: 79, y: 155, w: 975, h: 453 },
        { t: 6, x: 65, y: 92,  w: 1150, h: 535 }]
});

// any canvas, any frame: a pure function of time
AnnotationFX.draw(ctx, t, 1920, 1080, { style: 'lyell',
  mark: 'highlight', box: [118, 232, 1462, 680] });

      

    

  


  

    
Reference
Options

    

      
OptionWhat it does

      
        
style

        
markcircle, box, underline, strike, cross, highlight, bracket, arrow, note, connect

        
boxWhat to mark: [x, y, w, h], {x, y, w, h}, keyframes [{t, x, y, w, h}], a function of time, or a CSS selector or element.

        
noteText written beside the mark with a leader line. It goes to the side with the most room unless you set side.

        
side, fromright, left, top, bottom or auto for the note; from: the point an arrow starts at.

        
toconnect: the second box. The line runs from box to to.

        
space, fitpx (media pixels, default on images and video), norm (0 to 1) or css.

        
color, accent, textColor, highlightColor, fontRecolor any style or swap its handwriting.

        
scale, size, noteSize, noteWidth, pad, roughOverall size, text size and wrap width, room around the box, and how shaky the hand is (0 is steady).

        
haloA soft outline so ink reads over busy photos. true picks dark or light from the ink.

        
speedHow fast the hand draws: a number (2 is twice as fast) or slow, calm, normal, brisk, fast, snap. Set it once or per mark. It never moves an explicit delay.

        
duration, tempo, delay, stagger, hold, outTiming. delay: seconds after start, or 'wait' to hold the mark until it is fired. hold: 3 removes it 3 s after it lands, by fade or erase.

        
idA name for a mark, so fire('name') can start it.

        
marksSeveral marks in one overlay, each with its own options. They draw in order.

        
bleedPixels the overlay may extend past the element, so notes can run into the margin.

        
when, threshold, rootMargin, repeatStart when the element is visible (default), now, manual (call start or fire), or each: every mark whose box is an element fires as that element scrolls in. threshold and rootMargin tune "in view". repeat: true clears on leave and draws again on return.

        
syncVideo only. 'media' runs the clock on video.currentTime, so delay: 3.2 means 3.2 s into the video. It follows pause, seek and loop.

        
onStart, onMark, onDoneHooks. Each also fires as a bubbling DOM event: annotationfx:start, annotationfx:mark (detail: index, id, mark, time), annotationfx:done.

        
end, reducedMotionHold or clear at the end; hold, play or skip under reduced motion.

        
handleplay() returns start, stop, replay, pause, resume, fire, reset, seek(t) and time(). AnnotationFX.fire(el, which) does the same from anywhere.
